# Burak Seyhan — Resume

Personal resume site for [seyhanburak.com](https://www.seyhanburak.com/), built with Next.js and deployed on Netlify.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Deploy

Netlify is configured via `netlify.toml` with `@netlify/plugin-nextjs`. Push to `master` to trigger a deploy from the linked GitHub repo.
